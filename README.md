# AI 对话导出 · 小说阅读器

把 Gemini / Grok / ChatGPT / Claude 的对话从网页里抓下来，导出成 Markdown / JSON，再用一个**纯本地、单文件**的阅读器来读、整理、批注——适合把 AI 连载的小说存下来精读。

> 全程只做 DOM 文本搬运：不解析、不判断、不上传任何内容。数据只在你的浏览器里处理。

---

## 项目结构

```
ai-chat-novel-exporter/
├── userscript/
│   └── 导出对话.user.js     # 油猴脚本（边滚边采集，自动导出 .md + .json）
├── bookmarklet/
│   ├── 分享页导出.js         # 分享页导出（推荐，一次拿全）
│   ├── 导出对话.js           # 普通页导出 v2（备用）
│   └── 安装书签.html         # 书签安装页（拖拽即装，两种导出都有）
├── reader/
│   └── 对话阅读器.html       # 阅读器（单文件，双击即用）
└── examples/
    └── 示例数据.json         # 示例对话，用来试阅读器
```

## 快速上手

1. **导出对话**：打开 `bookmarklet/安装书签.html`，把「分享页导出」拖到书签栏；
   在 Gemini 对话页点「分享」→ 创建公开链接 → 打开 `share.gemini.google.com` 链接 → 点书签，自动下载 `.md` 和 `.json`。
   - 不想装书签？油猴插件用户直接装 `userscript/导出对话.user.js`（右下角会出现「导出对话」悬浮按钮）。
   - 普通对话页备用方案：控制台粘贴 `bookmarklet/导出对话.js`。
2. **阅读**：双击打开 `reader/对话阅读器.html`，把导出的 `.json` 拖进页面（或粘贴纯文本），即可按章节阅读。

## 阅读器功能

- **导入**：拖入导出的 `.json`，或粘贴纯文本（用 `u:` / `a:` 分隔标记切分）
- **四种视图**：我和 AI / 只看 AI / 只看我 / 按章节（自动识别「第X章 / Chapter / 番外 / 序 / 终章」等章节标记）
- **整理批注**：标高光 + 写点评、加备注、改标题、编辑正文、删除（带两步确认和回收站）
- **截断检测**：AI 回复末尾不像正常断句时自动标「可能被截断」
- **搜索**：正文关键词搜索，回车跳下一个
- **阅读体验**：深浅主题、衬线正文、目录跟随滚动
- **本地保存**：IndexedDB 存储（容量大，自动退回 localStorage）；「导出全部备份 / 导入备份」可搬家
- **导出**：把整理过的版本导出为 Markdown

## 工作原理

### 分享页导出（推荐）
Gemini 分享页是一次性完整渲染的，不需要滚动，不会漏内容。AI 回复没有可识别的标签，但用户消息有气泡（`<user-query>`）：
脚本给每个用户气泡前后插入隐形哨兵 → 取一次整体 `innerText` → 按哨兵切开——**两个用户气泡之间的内容就是 AI 回复**。取完立刻删掉标记，页面不留痕迹。

### 普通页导出（备用）
这些站会回收滚出视口的 DOM 节点，所以不能「先滚完再抓」，而是**边滚边采集、累积去重**：
四种滚动手段轮换（`scrollIntoView` / 各容器上移 / 派发 `wheel` / 归零），连续 8 轮没有新内容才停止。排序时若节点被回收过，按「发现批次倒序」恢复顺序。

## 数据格式

导出和导入使用统一的 JSON 结构（见 `examples/示例数据.json`）：

```json
{
  "source": "对话来源 URL",
  "title": "对话标题",
  "exportedAt": "导出时间 ISO",
  "detectedBy": "识别方式",
  "turnCount": 6,
  "turns": [
    { "index": 1, "role": "user", "text": "…" },
    { "index": 2, "role": "assistant", "text": "…" }
  ]
}
```

## 兼容性

- 导出脚本：Chrome / Edge / Firefox + 油猴（Tampermonkey），或直接控制台 / 书签
- 阅读器：任何现代浏览器，无需联网、无需安装，双击 HTML 即用
